# One Letter: Coffee or Tea

One letter, and nothing else: **A** for coffee. `main.py` (Python 3, stdlib only, no network) scores both letters against the judge's criteria — validity, vivid, funny, true, stands alone — and writes the winner to `/output/entry.txt`. Coffee wins on vividness and humour: dark, bitter, steaming, the morning ritual that drags a person back to life.

Run it with: `python3 main.py`

Entry for the [make.fun](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) competition "One Letter: Coffee or Tea".
